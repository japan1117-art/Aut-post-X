# Aut-post-X 実装ロードマップ（2026-10-24）
## 方針
初期10商品の登録はユーザーのExcel再アップロード待ち。登録が完了するまで、商品アフィリエイト投稿を本番有効化しない。
## 今回追加
- 商品台帳の入力前検査関数（`lib/product-validation.ts`）
- ASIN一致、Amazonドメイン、証跡欠落などのテスト
- 検証はオフラインの構造チェックのみ。短縮URLの転送先・販売状況・商品の正確性は検証しない。

3. エラー監視・重大指摘通知
4. 商品台帳DBマイグレーション、Excelインポート、審査キュー
5. 投稿タイプ配分と分析集計
6. キャンペーン応募者取得・抽選（API権限・法令・費用確認後、公開開始は別承認）
